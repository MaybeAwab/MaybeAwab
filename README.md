## Featured Project

### [Bahrain Flip Finder](https://github.com/MaybeAwab/bahrain-flip-finder)

A Python tool for evaluating used-electronics listings in Bahrain. It collects public
listings, removes duplicates, matches comparable products and estimates the room for
resale after transport, repairs and selling costs.

The pricing decision is deterministic: median-based comparisons, outlier filtering,
profit, ROI and maximum-buy calculations. Optional AI review checks model details and
obvious risks, while Telegram delivers the accepted opportunities.

`Python` `SQLite` `Data Processing` `Web Scraping` `Telegram` `AI APIs`
